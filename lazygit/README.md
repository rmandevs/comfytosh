# Comfytosh for lazygit

The [Comfytosh Theme](../README.md) port for [lazygit](https://github.com/jesseduffield/lazygit), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Merge the `gui.theme` block into `~/.config/lazygit/config.yml`.

## Files

- [`comfytosh-screen.yml`](comfytosh-screen.yml)
- [`comfytosh-case.yml`](comfytosh-case.yml)
