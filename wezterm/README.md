# Comfytosh for WezTerm

The [Comfytosh Theme](../README.md) port for [WezTerm](https://wezterm.org), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files in a `colors/` folder next to your `wezterm.lua`, then:

```lua
config.color_scheme_dirs = { wezterm.config_dir .. '/colors' }
config.color_scheme = 'Comfytosh Screen'
```
