# Comfytosh for Zed

The [Comfytosh Theme](../README.md) port for [Zed](https://zed.dev), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Copy `comfytosh.json` to `~/.config/zed/themes/` (Windows: `%APPDATA%\Zed\themes`), then pick a theme in the theme selector, or follow the system appearance:

```json
"theme": { "mode": "system", "light": "Comfytosh Case", "dark": "Comfytosh Screen" }
```
