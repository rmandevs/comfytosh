# Comfytosh for Starship

The [Comfytosh Theme](../README.md) port for [Starship](https://starship.rs), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Add `palette = "comfytosh_screen"` (or `"comfytosh_case"`) at the top level of `starship.toml`, paste the matching `[palettes.*]` table, and use the names in your formats: `accent`, `bg_raised`, `green`, `red`, `blue`, `purple` and so on.
