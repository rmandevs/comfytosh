# Comfytosh for bat

The [Comfytosh Theme](../README.md) port for [bat](https://github.com/sharkdp/bat), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Put the `.tmTheme` files in the `themes/` folder under `bat --config-dir`, run `bat cache --build`, then use `--theme="comfytosh-screen"`. The same themes work for delta.
