# Comfytosh for JetBrains IDEs

The [Comfytosh Theme](../README.md) port for [JetBrains IDEs](https://www.jetbrains.com), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Settings, Editor, Color Scheme, the gear menu, Import Scheme, then pick the `.icls` file. It colours the editor and the console; the window chrome stays on your current IDE theme (Darcula for Screen, Light for Case).

## Files

- [`comfytosh-screen.icls`](comfytosh-screen.icls)
- [`comfytosh-case.icls`](comfytosh-case.icls)
