Screen and Case

Screen is the dark glass: warm green-grey with phosphor ink. Case is the beige plastic, with the same hues pressed darker so every text colour clears 4.5:1.

Make a port

A port is a folder with both flavors, a README and a line in ports.json. Copy template/, map your tool to the roles in palette.json, then run python3 scripts/check_ports.py and open a pull request.
