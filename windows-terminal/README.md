# Comfytosh for Windows Terminal

The [Comfytosh Theme](../README.md) port for [Windows Terminal](https://github.com/microsoft/terminal), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Copy the two objects from `comfytosh.json` into the `schemes` array of your `settings.json`, then set `"colorScheme": "Comfytosh Screen"` on a profile.
