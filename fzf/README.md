# Comfytosh for fzf

The [Comfytosh Theme](../README.md) port for [fzf](https://github.com/junegunn/fzf), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Source the `.sh` file from your shell config.

## Files

- [`comfytosh-screen.sh`](comfytosh-screen.sh)
- [`comfytosh-case.sh`](comfytosh-case.sh)
