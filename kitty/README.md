# Comfytosh for Kitty

The [Comfytosh Theme](../README.md) port for [Kitty](https://sw.kovidgoyal.net/kitty/), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files in `~/.config/kitty/themes/` and add to `kitty.conf`:

```
include themes/comfytosh-screen.conf
```

## Files

- [`comfytosh-screen.conf`](comfytosh-screen.conf)
- [`comfytosh-case.conf`](comfytosh-case.conf)
