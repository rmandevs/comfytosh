# Comfytosh for Helix

The [Comfytosh Theme](../README.md) port for [Helix](https://helix-editor.com), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files in `~/.config/helix/themes/` and set `theme = "comfytosh-screen"` in `config.toml`.

## Files

- [`themes/comfytosh-screen.toml`](themes/comfytosh-screen.toml)
- [`themes/comfytosh-case.toml`](themes/comfytosh-case.toml)
