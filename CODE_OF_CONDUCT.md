# Code of conduct

Comfytosh is about making the screen a calmer place. The people around it should be too.

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- **Be kind.** Assume good intent, and give feedback on the work, not the person.
- **Be welcoming.** First ports, first pull requests and first questions are all welcome here. Nobody needs to apologise for not knowing something.
- **Be patient.** Maintainers are volunteers. A review may take a few days.
- **No harassment.** No insults, no discrimination, no unwelcome attention, no publishing other people's private information. Not in issues, pull requests, reviews, or anywhere else you represent the project.

## If something goes wrong

If someone makes you uncomfortable, contact the maintainer, [@rmandevs](https://github.com/rmandevs), privately, or use GitHub's *Report content* on the comment. Reports are kept confidential.

Maintainers may edit or remove comments, close threads, or block people who break this code, as described in the Contributor Covenant's enforcement guidelines.
