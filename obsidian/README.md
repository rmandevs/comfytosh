# Comfytosh for Obsidian

The [Comfytosh Theme](../README.md) port for [Obsidian](https://obsidian.md), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Make the folder `<vault>/.obsidian/themes/Comfytosh/`, put `theme.css` and `manifest.json` in it, then choose Comfytosh in Settings, Appearance. Screen is used in dark mode and Case in light mode.

- [`manifest.json`](manifest.json)
- [`theme.css`](theme.css)
