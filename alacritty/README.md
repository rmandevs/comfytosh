# Comfytosh for Alacritty

The [Comfytosh Theme](../README.md) port for [Alacritty](https://alacritty.org), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files in `~/.config/alacritty/themes/` and import one (Alacritty 0.14 or newer; older versions use a top-level `import`):

```toml
[general]
import = ["~/.config/alacritty/themes/comfytosh-screen.toml"]
```

## Files

- [`comfytosh-case.toml`](comfytosh-case.toml)
