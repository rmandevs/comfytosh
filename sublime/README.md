# Comfytosh for Sublime Text

The [Comfytosh Theme](../README.md) port for [Sublime Text](https://www.sublimetext.com), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files in `Packages/User/` and select the scheme from Preferences, Select Color Scheme.

## Files

- [`comfytosh-screen.sublime-color-scheme`](comfytosh-screen.sublime-color-scheme)
- [`comfytosh-case.sublime-color-scheme`](comfytosh-case.sublime-color-scheme)
