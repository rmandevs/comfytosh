# Comfytosh for btop

The [Comfytosh Theme](../README.md) port for [btop](https://github.com/aristocratos/btop), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Copy the `.theme` file to `~/.config/btop/themes/` and set `color_theme = "comfytosh-screen"`.
