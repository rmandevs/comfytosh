# Comfytosh for Ghostty

The [Comfytosh Theme](../README.md) port for [Ghostty](https://ghostty.org), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save both files in `~/.config/ghostty/themes/` and set, in your config:

```
theme = light:comfytosh-case,dark:comfytosh-screen
```
