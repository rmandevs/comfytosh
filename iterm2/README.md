# Comfytosh for iTerm2

The [Comfytosh Theme](../README.md) port for [iTerm2](https://iterm2.com), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Settings, Profiles, Colors, Color Presets, Import. Pick the `.itermcolors` file, then choose it from the same menu.

## Files

- [`comfytosh-screen.itermcolors`](comfytosh-screen.itermcolors)
- [`comfytosh-case.itermcolors`](comfytosh-case.itermcolors)
